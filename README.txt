WEDDING INVITATION WEBSITE - QUICK SETUP

1) Keep index.html, style.css, script.js and the assets folder together.
2) Open index.html in Chrome to preview the website.
3) Add your photographs inside the assets folder using these exact file names:
   bride.jpg       - Bride portrait
   groom.jpg       - Groom portrait
   couple.jpg      - Bride and Groom together
   gallery-1.jpg   - Pre-wedding photo 1
   gallery-2.jpg   - Pre-wedding photo 2
   gallery-3.jpg   - Pre-wedding photo 3
   family.jpg      - Family photograph
4) Edit names and wedding date near the top of script.js in the weddingDetails object.
5) Edit ceremony date, time, venue and description in index.html. Search for data-title="Dhaga Bandhan" and edit the data-date, data-time and data-venue values for each ceremony card.
6) Keep all files and the assets folder together when uploading to GitHub Pages.

IMPORTANT: The photo file names must match exactly. Use .jpg file names as shown, or update the matching src path in index.html if your photos are .png or .webp.
